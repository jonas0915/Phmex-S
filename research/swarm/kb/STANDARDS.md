# STANDARDS — how research is done here (violations = the thesis dies)

1. **Mechanism first.** A thesis names the counterparty and why they are forced to pay. "Indicator X crosses Y" is not a thesis.
2. **Internet-first sourcing (owner directive, ordered 2026-09-16 9:22 PM PT).** Every thesis must cite at least one external source URL (papers 2024-2026, practitioner live records, exchange/on-chain feeds) with the actual number that source reports. `DEAD_LIST.md` is a FILTER for rejecting relabels of things this account already killed — it is never a source of ideas. The gatekeeper verifies the cited sources and rejects any thesis whose key claim is unsupported or fabricated; the known failure mode is a real paper title paired with a made-up statistic.
3. **Pre-register, then read.** Spec + signal code are frozen (`registrar.freeze`) with a sha before any data is read. A frozen spec is never edited; a new idea is a new thesis.
4. **Closed bars only, and how re-entry works.** `screen.causality_check` fails any signal that changes when future bars are removed — it is a whole-prefix comparison run at every bar the signal fires plus 20 uniform points, on every symbol in the universe, exact equality; any mismatch kills the thesis outright. `screen.simulate`'s exit rule: the position is flat at the exit bar's close, so a signal on the exit bar enters at the next bar's open — there is no dead zone on the exit bar itself. Live slots that read the forming bar reproduce only ~40% of closed-bar replays — do not build on forming-bar signals.
5. **Signal values.** A signal function's output must be exactly `{-1, 0, 1}` at every bar; `screen.run_screen` raises if any other value appears.
6. **Train / holdout.** Holdout = final 25% of the dataset's range. `load_data.load_ohlcv` and `load_data.load_funding(symbol, era, token)` both refuse holdout rows without the committee token — funding is holdout-gated exactly like price data, anchored to the same era boundary. Holdout is read once, by the build stage, and recorded in the pre-reg doc. **Cross-dataset holdout caveat:** `long_1h` holdout (final 25% of 2025-06-27→2026-08-01) ≈ 2026-04-23→08-01; `mr_edge` train (2026-06-01→~08-10) falls inside that window, and 18 of the 19 `long_1h` symbols also exist in `mr_edge` — so `mr_edge` train data overlaps the `long_1h` holdout window. Rule: a thesis on the `long_1h` dataset may not use `mr_edge` data dated on or after 2026-04-23 in any exploratory probe or signal; the gatekeeper rejects a `long_1h` thesis whose probes did.
7. **Artifact naming.** `screen.run_screen` writes plain filenames (`out.json`, `trades.csv`) only for `era=="train"`. Any other era (e.g. `"holdout"`) writes era-suffixed files (`out.holdout.json`, `trades.holdout.csv`) in the same `screens/<id>/` folder, so a later holdout run never clobbers the train-era artifacts that the audit, committee, and knowledge base cite by path.
8. **Statistics come from `lib/`.** `bootstrap_ci.mean_ci` / `diff_ci` (independent resampling, sort only the diffs), `fee_math.p_star`. Hand arithmetic in prose is a defect.
9. **Multiplicity.** The Statistics committee seat applies Benjamini-Hochberg across all screens in the run, from each audit's `numbers.p_boot`; the auditor does not compute BH. Exactly one registered robustness read per thesis: perturb `tp_bps` by ±20% of its registered value (two variants — the +20% case and the −20% case), and it passes only if `net_bps_mean` keeps the same sign in both variants. This is not a grid; do not sweep further parameters or steps. Committee seats judge from `out.json` and `audit.json`; the frozen spec may be read for max_hold/universe and `trades.csv` for month-spread only.
10. **Fill realism.** Simulated fills are screening-grade upper bounds. Real maker fill ≈ 27%; adverse selection is in `c`. Forward test is the only adjudicator.
11. **Artifacts, not prose.** A candidate without `out.json` does not exist. Every number in a report links to a file. Orphaned artifacts are a critic finding.
12. **Never fabricate.** Run → read the tool output → write, with the path. "Not run" is a valid answer.
13. **Cite the dead list by row.** Every thesis lists its nearest dead rows and why the mechanism differs. The gatekeeper rejects relabels row-cited.
14. **Owner directives.** Never re-propose demoted books (main live, ST2.0, 5m_MR live, Donchian live), the BTC blacklist, gate loosening, universe swaps without a new mechanism, or the funding/XS/OI hunt. Plain English, verdict first.
15. **Reconcile.** Every screened thesis — pass or fail — becomes a row in DEAD_LIST.md or SURVIVORS.md; every process failure a dated line in LESSONS.md.
16. **Reference symbols.** A signal that needs a second symbol (a reference such as BTC) must load it through `load_data.load_reference(symbol, timeframe, dataset)` (or `load_reference_funding`), never through `load_ohlcv`/`load_funding` with an era argument — the screen supplies the era, so the same frozen signal is valid in both train and holdout. `screen.run_screen` sets that era via `load_data.screen_context(era, token)` around every signal call; the context never grants holdout on its own (the committee token is still required). `screen.causality_check` additionally clips every reference load to the last bar of the prefix it is testing (`load_data.reference_until`), so a forward transform confined to the reference series (e.g. `ref.close.shift(-3)`) is caught like any other lookahead — a signal must use only reference bars at or before the bar it fires on. A `signal_py` that calls `load_ohlcv`/`load_funding` with an explicit era is rejected at the gate (LESSONS 2026-09-19: the `informed_flow_btc_alt_cascade` holdout read was void, n=0, for exactly this reason).
